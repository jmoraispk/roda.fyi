# Inspiration

Reference material supplied during product design. These files document ideas
for dashboard statistics, coach communication, profiles, and human movement
illustrations.

## Interface references (`dashboard-ui/`)

- `dashboard-ui/group-statistics-ranking-reference.png` — ranked member cards,
  time-range filtering, and a longer leaderboard.
- `dashboard-ui/coach-feed-reference.png` — coach announcements, pinned posts,
  and reactions.
- `dashboard-ui/profile-overview-reference.png` — a photo-led member profile
  and settings entry points.
- `dashboard-ui/profile-edit-reference.png` — a richer profile-editing form.

## Movement-art references (`movement-art/`)

- `movement-art/human-movement-sequence-reference.png` — sequential human
  figures that make movement phases readable.
- `movement-art/capoeira-vector-style-reference.png` — a simplified illustrated
  capoeira figure style. The duplicate copy supplied with it was intentionally
  omitted.

These are internal inspiration references, not cleared production assets.
Their layouts and visual language may inform original roda.fyi work, but the
images themselves should not be shipped or reproduced without confirmed usage
rights.
